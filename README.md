# sema-linux 4.4.0
This is the repository for unified sema linux supporting TIVA BMC and EC

### Supported Hardware List:
* LEC-EL,LEC-ALN/ASL
* cExpress-TL , cExpress-EL, cExpress-AR, cExpress-ALN, cExpress-RLP, cExpress-MTL
* Express-ID7, Express-ADP, Express-TL, Express-RLP
* COM-HPC-cRLS, COM-HPC-sIDH, COM-HPC-mMTL
* NanoX-EL
* Q7-EL
* Express-VR7
* VPX3-TL
* cExpress-R8

### Supported Operating System:
* Ubuntu 18.04, 20.04, 22.04, 24.04
* Debian all versions
* CentOS 
* SuSE Linux
* Red Hat 9.0/9.4
